HOW TO PUT THIS ON GITHUB PAGES (free link)
1. Sign in at github.com, click "+" > New repository. Name it e.g. "birthday". Set it Public. Create.
2. Click "uploading an existing file", drag in index.html from this folder, then "Commit changes".
3. Go to Settings > Pages. Under "Build and deployment" choose Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. Wait 1-2 minutes. Your link will be:
   https://YOUR-USERNAME.github.io/birthday/
Passcode: 1234 (change it near the top of the script: CONFIG.passcode).
